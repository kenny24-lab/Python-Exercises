# Python Exercises

A collection of beginner-friendly Python programming exercises and small
console-based projects developed while learning and practicing Python
fundamentals.

## 📚 Project Overview

This repository contains practical Python exercises covering:

-   Variables and data types
-   User input and output
-   Arithmetic operations
-   Conditional statements
-   Loops
-   Lists
-   Strings
-   Functions
-   Basic problem solving
-   Small interactive console applications

## 🗂️ Projects and Exercises

  File                      Description
  ------------------------- -------------------------------------------
  `Area_rectangle.py`       Calculates the area of a rectangle
  `Average.py`              Calculates an average
  `Guessing_game.py`        Simple number guessing game
  `Password_Generator.py`   Generates passwords
  `Quiz_Game.py`            Interactive Python quiz game
  `Readtext_count.py`       Reads and counts text
  `Repeatedly_nbr.py`       Practices repeated number operations
  `Scalculator.py`          Simple calculator application
  `To_do_list.py`           Basic to-do list application
  `contact_Book.py`         Simple contact book
  `even_odd.py`             Checks whether a number is even or odd
  `listfruits.py`           Practices working with lists
  `multiple3_5.py`          Works with multiples of 3 and 5
  `names.py`                Practices working with names and strings
  `number_vowels.py`        Counts vowels in text
  `operation.py`            Performs basic mathematical operations
  `notes.txt`               Practice notes and supporting information

## 🚀 How to Run

### 1. Clone the repository

``` bash
git clone https://github.com/kenny24-lab/Python-Exercises.git
```

### 2. Open the project

``` bash
cd Python-Exercises
```

### 3. Run a Python file

For example:

``` bash
python Quiz_Game.py
```

You can replace `Quiz_Game.py` with any other `.py` file in the
repository.

## 💻 Requirements

Make sure Python is installed on your computer.

Check your Python installation with:

``` bash
python --version
```

or:

``` bash
py --version
```
